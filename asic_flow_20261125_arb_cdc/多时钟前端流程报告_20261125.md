# 多时钟 2 通道安全加密前端（des_arb_cdc_top）DC / PT / Formality 报告

日期：2026-11-25  
顶层：`des_arb_cdc_top`  
工具：DC / PrimeTime / Formality O-2018.06-SP1  
工艺库：Nangate45 `NangateOpenCellLibrary_typical`（只有 typical）  
结论：**三个时钟域 setup / hold 均 0 违例；Formality 7,073/7,073 通过。**

---

## 1. 结构

```
s0_axis (wclk0 100MHz) ──> async_axis_fifo(65b) ──┐
                                                   ├─> des_arb_soc_top (clk 250MHz)
s1_axis (wclk1 142.8MHz) ─> async_axis_fifo(65b) ──┘       仲裁 + DES + 单 AXIL
                                                              │
                                                              └─> m_axis (clk)
```

- 每个输入通道自己的写时钟域；`{tlast,tdata}` 拼成 65 位同字过域。
- 异步 FIFO 读侧 show-ahead：`fifo_fetch = can_fetch & (~rdata_v | fifo_fire)`，同拍 refill，背靠背每拍一个字。
- 三个时钟 `wclk0` / `wclk1` / `clk` 用 `set_clock_groups -asynchronous` 隔离。
- 每个域独立 2 级复位同步器（`reset_sync`）。
- 控制面：单 AXI4-Lite（clk 域），`0x000`=DES、`0x100`=仲裁器。

## 2. 面积

| 指标 | 数值 |
|---|---|
| Cells | 34,988 |
| Sequential (DFF) | 6,959 |
| **Total cell area** | **62,580.22 µm²** |

层次拆分：

| 模块 | 面积 (µm²) | 占比 |
|---|---|---|
| `u_core/u_des/u_axis/u_des`（DES 流水线） | 24,195.63 | 38.7% |
| `u_af0/u_fifo`（65×16 异步 FIFO） | 8,336.97 | 13.3% |
| `u_af1/u_fifo`（65×16 异步 FIFO） | 8,335.91 | 13.3% |
| `u_core/u_arb/u_fifo0`（65×16 同步 FIFO） | 7,771.99 | 12.4% |
| `u_core/u_arb/u_fifo1`（65×16 同步 FIFO） | 7,770.13 | 12.4% |
| 其余（仲裁、AXIL 译码、复位同步等） | ~6,170 | 9.9% |

**关键观察**：4 个 65×16 FIFO 合计 **32,215 µm² / 51.5%**。Nangate45 没有 SRAM 宏，所有小 FIFO 都用触发器阵列实现。这是“ASIC 里小存储用触发器堆”的真实代价，也是面试里讲面积取舍最有说服力的数字。

对比单时钟版本（`des_arb_soc_top`）：45,908 µm² / 4,663 DFF → 62,580 µm² / 6,959 DFF，面积 **+36%**、DFF **+49%**，主要来自两个异步 FIFO（各 1,040 FF）和复位/同步逻辑。

## 5. 边界（面试必须主动说）

- Nangate45 只有 **typical** 单角；没有 SS/FF，`set_timing_derate` 只是近似。
- 理想时钟、WLM、pre-CTS；没有真实时钟树和 SPEF。
- IO 预算：AXIS 写侧 2.0ns（各自 wclk），m_axis 2.0ns，AXIL 控制面 1.0ns；均为占位假设。
- 无 DFT/scan、无 P&R、无 UPF、无门级 SDF 后仿。
- 271 条 removal 是同沿保守悲观，已文档化，不 waive。
- 功耗未读 SAIF，未在本次报告中引用。

## 6. 面试 60 秒口径

> “我把 2 通道仲裁 + DES 做成多时钟前端：两路输入分别在 100MHz 和 142.8MHz 写域，经 65 位异步 FIFO（`{tlast,tdata}` 同字过域、show-ahead 同拍 refill）进 250MHz 的仲裁 + DES；三个时钟 `set_clock_groups -asynchronous`，每个域独立复位同步。VCS 14/14 通过。Nangate45 综合：62,580 µm² / 6,959 DFF，三个时钟域 setup/hold 都是 0 违例，250MHz 最差 reg2reg +1.51ns，Formality 7,073/7,073。四个 65×16 FIFO 占 51.5% 面积，因为 Nangate45 没有 SRAM 宏。边界是 typical 单角、理想时钟、pre-CTS，不是签核。”
