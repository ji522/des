# 2 通道 AXIS 仲裁 + DES SoC 前端流程报告（DC / PT / Formality）

日期：2026-11-25（更新：单 AXIL 控制端口 + 读数据打拍）  
工具：DC O-2018.06-SP1、PrimeTime O-2018.06-SP1、Formality O-2018.06-SP1  
工艺库：Nangate45 `NangateOpenCellLibrary_typical`（只有 typical）  
顶层：`des_arb_soc_top`（单 AXI4-Lite 控制端口，内部 `axil_2to1_demux` 地址译码）  
结论：**100MHz / 250MHz 单角 setup 与 reg2reg hold 均 0 违例；Formality 两版均 4,773/4,773 通过。**

---

## 1. 本轮改动

1. **AXIL 读数据打拍**：`axis_arb_regs.v` 的 `s_axil_rdata` 改为寄存器输出（`rdata_r`），切断“计数器/配置 mux → 输出端口”的组合路径。250MHz 原本 52 条 `s_axil_arb_rdata[*]` 违例全部消失。
2. **单 AXIL 控制端口**：新增 `axil_2to1_demux.v`，一个 AXI4-Lite 从端口按 `addr[8]` 译码：
   - `0x0000–0x00FF` → DES 寄存器
   - `0x0100–0x01FF` → 仲裁器寄存器
   - 单 outstanding；W 等 AW 先到；AR 握手锁存选择，R 按锁存回送。
3. **控制面/数据面 IO 预算分层**：AXI4-Lite 控制面 1.0ns，AXIS 数据面 2.0ns。这是常见 SoC 预算假设，已明确写进 SDC；不是把所有 IO 放宽。
4. 回归：VCS **13/13 PASS**（集成用例改为单 AXIL 端口，地址 `0x000` / `0x100`）。

---

## 2. 流程与关键修正

- **必须用 `analyze → elaborate → link`，不能用 `read_file`**。参数化实例（`sync_fifo`、`axis_arb2`、`axis_arb_regs`）用 `read_file` 会被静默丢成空引用。
- 综合后实例自检：
  - `sync_fifo=2`
  - `axis_arb2=1`
  - `axis_arb_regs=1`
- `dc_arb.tcl` 内 `set_svf`，Formality 读同一个 SVF。
- PT 的 1 条 error 是 `PT-063: Library Compiler executable path is not set`，工具环境提示，不影响时序报告。

## 3. 100MHz（10ns）结果

### 3.1 面积

| 指标 | 数值 |
|---|---|
| Cells | 26,591 |
| Sequential (DFF) | 4,663 |
| Combinational area | 约 23,600 µm² |
| Noncombinational area | 约 22,300 µm² |
| **Total cell area** | **45,907.88 µm²** |

层次拆分：

| 模块 | 面积 (µm²) | 占比 |
|---|---|---|
| `u_des/u_axis/u_des`（DES 16 级流水） | 24,207.60 | 52.7% |
| `u_arb/u_fifo0`（16×65 同步 FIFO） | 7,777.84 | 16.9% |
| `u_arb/u_fifo1`（16×65 同步 FIFO） | 7,777.84 | 16.9% |
| 其余（仲裁、AXIL 译码/寄存器、边带 FIFO、复位同步等） | ~6,144 | 13.5% |

**关键观察**：Nangate45 没有 SRAM 宏，两个 16×65 FIFO 被综合成触发器阵列，合计 **15,556 µm² / 33.9%**。这是“ASIC 里小存储用触发器堆”的真实代价。

### 3.2 时序

| 指标 | 数值 |
|---|---|
| DC setup WNS / TNS | 0.00 / 0.00（0 违例） |
| DC hold WNS / TNS | 0.00 / 0.00（0 违例） |
| PT clk setup 违例 | 0 |
| PT clk hold（reg2reg）违例 | 0 |
| PT reg2reg 最差 slack | **+7.4383 ns** |
| PT async_default hold | 244 条 removal，slack ≈ −0.10 ns |

最差 reg2reg 路径：
- Startpoint：`u_des/u_axis/u_des/pipe_stages[15].u_round/valid_o_reg`
- Endpoint：`u_arb/ch1_stall_o_reg[31]`
- 是“DES 输出 valid → 仲裁器 stall 计数器”的使能路径，不是 DES 数据通路。

removal 244 条：复位同步器 `rst_sync_r_reg` 的 CK→Q 与下游异步复位端同沿检查，PT 同沿保守悲观；物理上复位撤销要到下一拍才被采样。与 11-08 的 243 条同类，**刻意保留可见，不 waive**。

### 3.3 功耗（估算，非签核）

| 指标 | 数值 |
|---|---|
| Dynamic | 3.03 mW |
| Leakage | 0.92 mW |
| Total | 约 3.96 mW |
| clock_network | 0.00%（理想时钟，未 propagate） |
| register | 约 84% |

边界：未读 SAIF、WLM 无真实线载、理想时钟，只能当相对趋势。

## 4. 250MHz（4ns）结果

### 4.1 面积

| 指标 | 数值 |
|---|---|
| Cells | 26,456 |
| Sequential (DFF) | 4,663 |
| Total cell area | 45,869.31 µm² |

与 100MHz 基本相同（DFF 数不变）。

### 4.2 时序

| 指标 | 数值 |
|---|---|
| DC setup WNS / TNS | 0.00 / 0.00（0 违例） |
| DC hold WNS / TNS | 0.00 / 0.00（0 违例） |
| PT clk setup 违例 | **0** |
| PT clk hold（reg2reg）违例 | **0** |
| PT reg2reg 最差 slack | **+1.7302 ns** |
| PT async_default hold | 186 条 removal，slack ≈ −0.10 ns |

最差 reg2reg 路径：
- Startpoint：`u_arb/u_fifo1/count_r_reg[0]`
- Endpoint：`u_arb/ch1_blocked_o_reg[31]`
- 是 FIFO 占用计数 → blocked 计数器的路径，不是 DES 数据通路。

**关键对比**：
- 改前（两个 AXIL 端口、读数据组合输出）：250MHz 有 52 条 `s_axil_arb_rdata[*]` setup 违例，WNS −0.96ns。
- 改后（读数据打拍 + 单端口译码 + 控制面 1.0ns 预算）：**setup 0 违例，reg2reg +1.73ns**。
- 如果不放宽 AXIL 控制面预算（统一 2.0ns），还剩 2 条 `awaddr[8]→awready` / `araddr[8]→arready` 组合路径，slack 约 −0.25/−0.19ns；这是 demux 地址译码到 ready 的纯组合路径。

## 6. 边界（面试必须主动说）

- Nangate45 只有 **typical** 单角，没有 SS/FF；`set_timing_derate` 只是近似，不是签核。
- 理想时钟、WLM、pre-CTS；没有真实时钟树和 SPEF。
- IO 预算：AXIS 数据面 2.0ns、AXIL 控制面 1.0ns，均为占位假设，真实值应来自系统接口。
- 无 DFT/scan、无 P&R、无 UPF、无门级 SDF 后仿。
- 100MHz 的 244 条 / 250MHz 的 186 条 removal 是同沿保守悲观，已文档化，不 waive。
- 功耗未读 SAIF，只能报相对趋势。

## 7. 面试 60 秒口径

> “我把 2 通道仲裁器和 DES 集成后跑了 DC→PT→Formality：单 AXIL 端口内部做 0x000/0x100 地址译码，读数据打一拍。100MHz 和 250MHz 单角下 setup 与 reg2reg hold 都是 0 违例；250MHz reg2reg 最差 +1.73ns。面积约 45,900 µm²、4,663 个 DFF，其中两个 16×65 FIFO 占 34%，因为 Nangate45 没有 SRAM 宏，小 FIFO 只能堆触发器。Formality 两版都是 4,773/4,773。边界是 typical 单角、理想时钟、pre-CTS、控制面 IO 1.0ns 预算，不是签核。”
